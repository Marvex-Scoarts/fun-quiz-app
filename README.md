#  Ultimate Family Neon Quiz 

An interactive, dark-mode + neon arcade trivia game built from scratch for our family get-together! Designed for two teams to battle it out across 50 fun, educational, and brain-teasing questions.

**Play the Live Game Here:** `https://marvex-scoarts.github.io/fun-quiz-app/

---

## Features

- **50-Question Family Party Pack:** Covers Animals, Science & Space, Food Trivia, World History, and Brain Teasers.
- **Smart Question Shuffler:** Randomizes all 50 questions every round so no two games play the same.
- **Team 1 vs. Team 2 Battle Mode:** Automatically alternates turns and tracks live scores for both teams.
- **15-Second Countdown Timer:** Keeps every round fast-paced and exciting.
- **Built-In Retro Arcade Sound Effects:** Generates custom sound effects for right answers, wrong answers, and victory fanfare using the Web Audio API (no external audio files required!).
- **Offline Neon Confetti Celebration:** Launches a custom HTML5 Canvas neon confetti burst on the winner screen.
- **Dark + Neon UI:** Sleek dark-mode interface paired with glowing cyan, magenta, and lime highlights.

---

## Built With

- **HTML5** – App structure and game screens
- **CSS3** – Custom dark-neon styling, CSS Grid layout, and glow animations
- **Vanilla JavaScript (ES6)** – Game logic, timer, Web Audio API synthesizer, and HTML5 Canvas confetti

---

## How to Play

1. Open the live website link on a laptop, tablet, or TV screen.
2. Split into **Team 1** and **Team 2**.
3. Read the question aloud and click an answer before the **15-second timer** hits zero!
4. Watch the scoreboard update automatically as turns alternate between teams.
5. Celebrate the winning team with neon confetti and hit **Play Again** for a freshly shuffled rematch!
## To Run Locally on Your Computer

1. Download or clone this repository.
2. Open the project folder (`quiz-app`).
3. Double-click `index.html` to launch the game in any web browser—no installation or internet connection required!
